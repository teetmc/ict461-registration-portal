# AI Use

## Purpose
I used AI assistance to understand the ICT461 Web Standards and HTTP Fundamentals lab and to receive step-by-step guidance while building my course registration portal.

## AI assistance used

### 1. HTML structure
- Request: I asked for guidance on how to structure the registration form according to the lab requirements.
- AI suggestion: The AI explained semantic elements such as header, nav, main, footer, linked labels, required fields, submit buttons, and visible feedback.
- Use: Used.
- My work: I wrote and modified the HTML myself based on the explanations.

### 2. Accessibility
- Request: I asked what `aria-live="polite"` means.
- AI suggestion: The AI explained that it helps screen readers announce changes to a webpage without unnecessarily interrupting the user.
- Use: Used.
- Test: I tested keyboard navigation using the Tab key and confirmed that the interactive fields received visible focus outlines.
- Learning: I learned how accessibility features can help users who rely on screen readers and how keyboard users can navigate a form.

### 3. CSS and responsive design
- Request: I asked for step-by-step guidance on styling the registration form and making it responsive.
- AI suggestion: The AI explained CSS Grid, Flexbox, `max-width`, padding, and media queries.
- Use: Used.
- Test: I tested the page at a small screen size and a desktop size and checked that the elements did not overlap.
- Learning: I learned that `max-width` allows an element to become smaller on a narrow screen, while a fixed width can cause overflow.

## AI-generated code
I did not request a complete solution or full project code. I received small code examples while being guided through the lab and implemented the changes myself.

## Verification
I tested the changes in my browser and checked the page layout and keyboard navigation myself.
